# Project Specification: Interactive Port Killer

## 1. 프로젝트 개요 (Overview)
* **목표:** 특정 포트를 점유하고 있는 프로세스를 찾고, 방향키 인터페이스를 통해 선택하여 간편하게 강제 종료(Kill)하는 CLI/TUI 툴 개발.
* **타겟 환경:** macOS / Linux (Windows는 향후 확장 고려)
* **제한 시간:** 약 1시간 ~ 1시간 30분 (점심시간 프로젝트)

## 2. 기술 스택 (Tech Stack)
* **언어:** Rust
* **핵심 라이브러리 (Crates):**
  * `inquire`: 터미널 내 방향키 이동, 선택, 확인 프롬프트 등 인터랙티브 UI 구현
  * `sysinfo`: 프로세스 정보 조회 및 안전한 프로세스 강제 종료(Kill) 처리
  * `std::process::Command`: OS 내장 명령어(`lsof` 또는 `netstat`) 호출 및 텍스트 출력 파싱

## 3. 핵심 기능 명세 (Features)

### 3.1. 포트 및 프로세스 정보 수집
* OS 명령어를 백그라운드에서 실행하여 현재 사용 중인 포트와 해당 포트를 연 프로세스(PID) 정보를 획득한다.
  * *macOS/Linux 명령어 예시:* `lsof -iTCP -sTCP:LISTEN -P -n`
* 출력된 결과 텍스트를 파싱하여 `[포트 번호, 서비스명, PID]` 형태의 구조체(Struct) 리스트로 변환한다.

### 3.2. 인터랙티브 UI (TUI)
* 파싱된 리스트를 `포트 | 서비스명 (PID: 0000)` 형태의 직관적인 문자열 배열로 가공한다.
* `inquire::Select`를 사용하여 화면에 목록을 출력하고, 사용자가 `위/아래 방향키`로 이동 후 `Enter`를 눌러 특정 항목을 선택할 수 있게 한다.

### 3.3. 안전한 프로세스 종료 (Kill)
* 항목이 선택되면 `inquire::Confirm`을 사용하여 "정말 [서비스명] 서비스를 Kill 하시겠습니까? (y/N)" 형태의 확인 프롬프트를 띄운다.
* 사용자가 `y`(yes)를 선택할 경우:
  * 매핑되어 있던 대상 PID를 추출한다.
  * `sysinfo` 라이브러리를 통해 해당 PID를 가진 프로세스에 Kill Signal을 전송하여 안전하게 종료한다.
  * 성공/실패 여부를 터미널에 메시지로 출력한다.
* 사용자가 `N`(no)를 선택할 경우 명령을 취소하고 프로그램을 종료한다.

## 4. 개발 마일스톤 (Milestones)

* **Step 1 (UI 프로토타이핑):** 가짜 데이터(Mock String) 리스트를 만들고 `inquire`를 연동하여 방향키 선택 및 확인 창이 정상 동작하는지 테스트한다.
* **Step 2 (정보 수집 로직):** `Command`를 활용해 `lsof` 결과를 가져오고, 정규식이나 문자열 split을 이용해 포트와 PID를 정확히 파싱하는 로직을 작성한다.
* **Step 3 (프로세스 종료 로직):** 추출한 PID를 기반으로 `sysinfo`를 이용해 실제 프로세스를 죽이는 코드를 연결한다.
* **Step 4 (폴리싱):** 터미널 출력 화면을 깔끔하게 다듬고 (예: 테이블 간격 맞추기, 색상 추가), 에러 처리(권한 부족, 파싱 실패 등)를 보강한다.
